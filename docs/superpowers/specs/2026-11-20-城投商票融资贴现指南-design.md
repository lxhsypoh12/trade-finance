## 1. 意图（为什么做）

业务模式指南模块（2026-10-31 上线，见 `2026-10-31-业务模式指南与错误日志-design.md`）已收录 3 个业务
（受托支付、城投商票质押贷款、个人存单质押贷款）。现新增第 4 个业务「城投商票融资贴现业务」，
目的与模块初衷一致：同事对该业务整体流程不熟悉时，有流程图＋环节注意事项可查，避免漏细节犯错。

## 2. 目标 / 非目标 / 反目标

### 目标
- `GUIDE_DATA` 新增一个条目（key `city-cp-discount`），格式与现有 3 条完全一致：
  legend（参与方/贸易链/实质）＋ stages ＋ nodeNames ＋ layouts（坐标＋context 货流）＋ steps（编号箭头）。
- 系统业务类型清单 `BIZ_TYPES` 新增「商票融资贴现」（用户指定名字；插到「其他」之前），
  指南 `linkedBizTypes:['商票融资贴现']`，错误记录弹窗按此过滤。
- 流程图与手画素材一致：单张总图、①–⑦ 编号箭头、主贸易链灰虚线货流。
- 注意事项（guide_notes）、错误记录联动（error_logs）、编号圆点跳转：全部复用现有机制，零新代码。

### 非目标
- 不建新 Supabase 表、不建新 view、不改 Guide 对象任何渲染代码。
- 流程结构不做在线编辑；手画照片不嵌入页面（沿用原设计决定）。
- `LOAN_BIZ_TYPES`（贷款统计下拉）不加「商票融资贴现」——该业务非贸易子公司贷款类（Claude 决定）。
- 不改现有 3 个指南、不改其他任何模块。

### 反目标
- 改坏现有指南/模块的任何功能。
- 引入外部 JS/CSS 库。

## 3. 约束（沿用现有架构）

- 单文件 `贸易金融业务管理系统（Supabase）.html` 内修改；完成后 `cp` 同步 `index.html`；
  git commit + push；GitHub Pages 部署（1-3 分钟）后线上验收。
- 每完成一个 Step 用大白话解释，等用户回复"通过"再继续（项目 CLAUDE.md 规则）。
