状态：**用户已回复"通过"批准（含三轮修订：加Excel导出/手动增删改、排序从近到远、开票年月范围筛选），可动工**

素材：`财务看板资料\全量发票查询导出结果.xlsx`（财务日常统计模版）

## 1. 背景与意图（为什么做）

同事需要查看自营公司开具的发票。财务日常已用固定 xlsx 模版统计发票；本看板让财务"上传模版即入库"，
同事自助查看/筛选/导出发票明细，并以"是否使用"勾选标记发票占用状态（红/绿一眼可辨）。

## 2. 目标 / 非目标 / 反目标

### 目标
- 财务板块（主页第三分区）新增卡片「🧾 自营发票统计」，点击进入新视图 `view-invoice`。
- 上传 xlsx 模版：自动抓取 6 个标黄字段（数电发票号码/销方名称/购买方名称/开票日期→年月/货物或应税劳务名称/价税合计）入库；按发票号去重：已存在＝覆盖更新其余字段且**保留 used**，不存在＝新增；上传后提示"新增 N 条、更新 M 条"。
- 明细表 7 列：6 字段＋"是否使用"勾选列（勾选整行红 #fed7d7、未勾选整行绿 #c6f6d5，点勾选即时 PATCH 保存）＋操作列（✎/🗑）。
- 手动增删改：＋新增（插入空行直接行内编辑）、行内编辑、删除（confirm）。交互镜像 LoanStats。
- 筛选（可组合）：销方/购买方/货物名称＝下拉（选项取自现有数据distinct）；是否使用＝是/否/全部；
  **开票年月＝起/止两个年月选择器（任留空＝不限该端）**。除数电发票号码外全覆盖（用户指定）。
- 排序：开票年月从近到远；同月按 id 倒序（用户指定）。
- 价税合计列底部合计＝**当前筛选结果**之和（千分位 2 位小数）。
- 导出 Excel：当前筛选结果所见即所得（含合计行），"是否使用"导出为"是/否"；沿用系统 xls 机制（BOM＋xlsText 防注入）；文件名 `自营发票统计_YYYYMMDD.xls`。**不做 PDF**（用户指定）。
- 数据存 Supabase 新表 `self_invoices`，多人共享。

### 非目标
- 不做 PDF 导出、不推飞书日报、不做批量删除、不做密码门（财务看板密码门不动）。
- 不解析模版中非标黄字段；不嵌入/存储 xlsx 文件本身。

### 反目标
- 引入构建工具/node_modules；解析库不得在页面加载时阻塞或拖累其他模块（懒加载）。
- 上传把历史勾选状态冲掉。
- 改坏现有任何模块。

## 4. 模版勘察结论（2026-11-23 实测）

- 工作表：['信息汇总表','发票基础信息']；数据在首表，表头第 1 行，共 27 列。
- 标黄（FFFFFF00）6 列：D 数电发票号码（文本）、F 销方名称、H 购买方名称、I 开票日期（**文本** 'YYYY-MM-DD HH:MM:SS'）、L 货物或应税劳务名称、T 价税合计（**数字**，元）。
- 解析策略：**按表头文字定位列**（非固定列位），并扫描所有工作表找含"数电发票号码"表头者——模版列序/表名变化不破坏解析。
- 年月提取：文本取前 7 位并校验 ^\d{4}-\d{2}；若遇日期对象则格式化；开票日期为空/发票号为空的行跳过。

## 6. 模块设计

### 6.1 Supabase 新表 `self_invoices`（Step 1 用户控制台执行）

```sql
CREATE TABLE self_invoices (
  id BIGSERIAL PRIMARY KEY,
  invoice_no TEXT NOT NULL DEFAULT '',     -- 数电发票号码
  seller TEXT NOT NULL DEFAULT '',         -- 销方名称
  buyer TEXT NOT NULL DEFAULT '',          -- 购买方名称
  period TEXT NOT NULL DEFAULT '',         -- 开票年月 'YYYY-MM'
  goods TEXT NOT NULL DEFAULT '',          -- 货物或应税劳务名称
  amount NUMERIC NOT NULL DEFAULT 0,       -- 价税合计（元）
  used BOOLEAN NOT NULL DEFAULT false,     -- 是否使用
  created_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE self_invoices ENABLE ROW LEVEL SECURITY;
CREATE POLICY "允许匿名读取" ON self_invoices FOR SELECT TO anon USING (true);
CREATE POLICY "允许匿名插入" ON self_invoices FOR INSERT TO anon WITH CHECK (true);
CREATE POLICY "允许匿名更新" ON self_invoices FOR UPDATE TO anon USING (true) WITH CHECK (true);
CREATE POLICY "允许匿名删除" ON self_invoices FOR DELETE TO anon USING (true);
```

### 6.2 REST 封装（命名沿用现有）

```js
invGetAll()           // GET  self_invoices?order=id.asc
invInsert(records)    // POST Prefer: return=representation
invUpdate(id,fields)  // PATCH ?id=eq.{id}
invDelete(id)         // DELETE ?id=eq.{id}
```

### 6.3 前端对象 `InvoiceStats`（镜像 LoanStats 交互）

- `render()` — 拉数→筛选→排序（period desc, id desc）→渲染表格＋合计行＋筛选器选项刷新。
- `onFile(evt)` — 懒加载 SheetJS → `XLSX.read` → `_parseWorkbook(wb)` → 与现有发票号比对 → 批量 insert 新行＋逐条 update 已存在行（不碰 used）→ alert 汇总 → render。
- `_parseWorkbook(wb)` — 纯函数（可单测）：找表→表头定位 6 列→行转记录（period/amount 规范化、空发票号跳过）。
- `addRecord()` / `startEdit(id)` / `saveEdit(id)` / `cancelEdit()` / `deleteRecord(id)` — 行内 CRUD；编辑控件：文本×4、`<input type="month">`（period）、number（amount）、checkbox（used）。
- `toggleUsed(id,checked)` — PATCH used → render（保持当前筛选）。
- `exportExcel()` — 筛选结果＋合计行 → xls（BOM＋xlsText）。
- 筛选状态：`_f={seller:'',buyer:'',goods:'',used:'',from:'',to:''}`；下拉 distinct 取自全量数据；年月范围比较用字符串字典序（'YYYY-MM' 天然可比）。
