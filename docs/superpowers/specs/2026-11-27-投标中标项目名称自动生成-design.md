## 意图与原因

完成阶段表的项目名称自动生成（同日上线，规格见 2026-11-27-完成阶段项目名称自动生成-design.md）验收后，用户要求投标、中标两张表照同一模式在第一列增加"项目名称"自动填写列，唯一差异：名称中的时间取各表自己的"时间"列（数据字段三阶段同名 time，函数无需区分）。目的：三阶段口径统一、免手工、记录可辨识。

## 目标

- 投标/中标表第一列显示系统自动生成的项目名称，灰色只读，表头小字「(系统自动生成)」，样式与完成表一致
- 复用既有 `autoProjectName(r)`（单源，零新函数）：金融机构 + 时间规整6位年月 + 业务类型 +（规模，≥1亿换算亿去尾零）
- 生成时机：
  - 投标表改 金融机构/时间/业务类型/业务规模 任一格 → 重生成，**原地更新名称文字，不整表刷新**（保护连续录入体验）
  - 中标表改 业务规模/业务类型 → 同上（金融机构/时间在中标表只读）
  - 投标→中标两条迁移路径（migrateBidToWin 勾选迁移、selectQuote 报价选定）→ 名称随记录生成入库
  - 新建投标记录（addBid）→ 模板含空 project_name，字段边填名称边成形
- 存量一次性补齐（用户拍板）：先重新备份 trade_stats，再以**同一函数源码**（node 脚本从 HTML 提取 eval，杜绝两套实现漂移）给 bid/win 空名称行生成写回；只填空白、绝不覆盖非空；完成阶段那条空名记录**不补**（前一轮「存量不动」决定）
- Excel 导出：bid/win 表头及数据行第一列（序号后）加「项目名称」，xlsText 防注入；PDF 打印照 DOM 自动跟随

## 非目标

- 完成表行为零改动（保持整表刷新模式，其 Minor#2 不在本次范围）
- 贷款/子公司/发票/财务看板各表不动
- 中标→完成迁移不动（前一轮已实现）
- 飞书推送不动（不读 project_name，已实证）

- bid/win Excel 导出错列、注入失活失效
- 页面生成与补齐脚本生成规则不一致（同名不同果）

## 实现要点（留给构建者）

- thead 459/466：cb 列后加 `<th>项目名称<br><span style="font-weight:400;font-size:10px;color:#a0aec0">(系统自动生成)</span></th>`
- bid/win 行模板：cb td 后加 `<td><span class="readonly-cell" id="pname-{stage}-{id}">'+escHtml(r.project_name||'')+'</span></td>`；done 渲染不动
- cellUpdate：重生成条件扩为 stage∈{bid,win,done} × field∈{time,biz_type,amount,bank}（缓存查找用 this._cache[stage]、String 归一 id）；保存后缓存行同步写 project_name；bid/win 以 getElementById('pname-'+stage+'-'+id).textContent 原地更新（done 沿用整表刷新，两机制并存不冲突）
- migrateBidToWin：`r.project_name=autoProjectName(r)`（stage 已改 win 后、入库前）；selectQuote：同点位加同一行
- addBid 模板加 project_name:''
- exportExcel：cols.bid/cols.win 首位加'项目名称'；bid/win 数据行首加 `xlsText(r.project_name)` 单元格
- 补齐脚本（E:\tmp\backfill_names.mjs，node 原生 fetch）：GET bid/win → 过滤 project_name 空白行 → 从 HTML 正则提取 autoProjectName 函数源码 eval 复用 → 逐条 PATCH {project_name,updated_at} → 重拉验证计数；Supabase URL/Key 用项目 CLAUDE.md 所载 publishable 凭据
- 测试（e:\tmp\sdd-test\bidwinname.test.mjs 新文件）：A bid 渲染（表头/只读格/span id/colspan 10/空表 10）；B win 渲染（同、colspan 14/空表 14）；C cellUpdate 重生成＋原地更新＋无整表刷新（GET 计数不变）＋无关字段不触发；D 两条迁移路径 POST 带名；E Excel bid/win 首列＋注入失活。既有 statsexcel（includes 型断言）预计不破，全量回归验证
