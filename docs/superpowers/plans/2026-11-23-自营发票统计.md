# 自营发票统计看板 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **本项目例外：** 项目 CLAUDE.md 已给定执行方式＝主对话直接执行（不派子代理），且每完成一个 Task 用大白话解释、等用户回复"通过"再继续。

**Goal:** 财务板块新增「🧾 自营发票统计」看板：上传财务 xlsx 模版自动入库 6 字段、明细 7 列＋红绿勾选、组合筛选（含开票年月范围）、从近到远排序、合计行、Excel 导出、行内增删改。

**Architecture:** Supabase 新表 `self_invoices`＋单文件 HTML 内新视图 `view-invoice`＋前端对象 `InvoiceStats`（镜像 LoanStats 交互）；xlsx 解析靠 SheetJS CDN 懒加载（仅上传时注入 script）；解析核心 `_parseWorkbook(wb)` 为纯函数便于 jsdom 单测（测试以 stub `window.XLSX` 注入假 workbook）。

**Tech Stack:** 单文件原生 HTML/CSS/JS；jsdom 回归（`e:/tmp/sdd-test/*.test.mjs`）；SheetJS xlsx-0.20.3（CDN：https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js）。

**Spec:** `docs/superpowers/specs/2026-11-23-自营发票统计-design.md`

## Global Constraints

- 单文件架构：产品改动只在 `贸易金融业务管理系统（Supabase）.html`；禁构建工具/node_modules。
- 改完 cp 同步 index.html → commit → push → Pages 验收；每 Task 大白话解释＋等"通过"。
- 金额单位元、千分位 2 位小数显示；行着色 #fed7d7(used)/#c6f6d5(未used)；RLS 匿名四政策。
- 不做 PDF/飞书/批量删除/密码门。
- 既有惯例：xlsText(html:803) 防注入、LoanStats(html:1156) 行内编辑模式、exportExcel xls 拼装(html:1269/2330/2540)。

## Review Focus

1. 重传模版不得清掉 used、不得重复插行（按 invoice_no upsert）→ Task 3 断言：预置 used=true 行后重传，该号走 PATCH 且 body 不含 used、无对应 POST。
2. 年月范围筛选边界含端点、单端留空＝开放 → Task 5 断言矩阵。
3. 排序 period 字典序 desc＋同月 id desc → Task 2 断言（混月份+同月多行）。
4. 导出＝筛选所见即所得：含合计行、是否使用→是/否、BOM＋xlsText 转义、文件名 自营发票统计_YYYYMMDD.xls → Task 5 断言。
5. 脏模版行（空发票号跳过、金额为字符串归一、日期对象/异常文本年月兜底）不崩 → Task 3 `_parseWorkbook` 断言。
