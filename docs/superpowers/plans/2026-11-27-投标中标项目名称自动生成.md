# 投标/中标「项目名称」自动生成 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 投标/中标统计表第一列新增系统自动生成的"项目名称"只读列（复用 autoProjectName），并把线上 48 条空名存量一次性补齐。

**Architecture:** 复用既有 `autoProjectName(r)` 单源函数（bid/win/done 三阶段字段同名同构）。渲染加只读 span（带元素 id）；cellUpdate 重生成条件从 done 扩到三阶段并新增 bank 字段，bid/win 用 getElementById 原地更新文字**不整表刷新**（done 保持既有整表刷新）；两条 bid→win 迁移路径入库前生成；Excel bid/win 首列加名称。存量补齐用 node 脚本从 HTML **提取函数源码 eval**（规则同源零漂移），只填空白行。

**Tech Stack:** 纯 HTML+JS 单文件；测试 jsdom（e:\tmp\sdd-test）；补齐脚本 node 24 原生 fetch（E:\tmp，不入库）。

**Spec:** `docs/superpowers/specs/2026-11-27-投标中标项目名称自动生成-design.md`

## Global Constraints

- 改动仅 `贸易金融业务管理系统（Supabase）.html`；每 Task 提交前 `cp` 同步 `index.html`，两文件一起 commit（项目 CLAUDE.md 铁律）
- trade_stats 表结构零变更；名称与源字段并入**同一次 PATCH**
- **done 表渲染与刷新行为零改动**（无 span id、仍整表刷新，前一轮已验收）
- 补齐脚本：只填 stage∈{bid,win} 且 project_name 空白（trim 后空串）的行；done 那条空名记录**不补**；执行前必须先落地当日全表备份 JSON
- Supabase 凭据用项目 CLAUDE.md 所载 URL＋publishable key
- 测试命令：`cd /e/tmp/sdd-test && node <文件>.test.mjs`；全量 `bash run-suite.sh`（退出码 0）

## Review Focus

1. 投标表连续录入保护：改一格名称原地更新、**同一 DOM 节点**不换、无新 GET（不整表刷新）、勾选不丢 → Task 2 C1
2. 两条迁移路径（勾选迁移按钮、报价"选定"）都带名入库 → Task 3 D1/D2
3. 补齐脚本只填空白、绝不动 done：dry-run 计数核对＋写后重拉验证 done 名称与备份逐条一致 → Task 5
4. 页面与脚本生成规则同源（脚本 eval HTML 内函数源码）：样本行输出与页面 A 段向量一致 → Task 5
5. Excel bid/win 注入失活（`=恶意名` 加引号前缀）与列序（序号|项目名称|区域…） → Task 4 E 段
6. colspan：bid 报价展开行=10、空表提示 bid=10/win=14 → Task 1 A/B 段
