# 完成阶段「项目名称」自动生成 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成阶段统计表「项目名称」由手填改为系统按「金融机构+年月+业务类型（规模）」自动生成并落库，格子只读。

**Architecture:** 新增全局纯函数 `autoProjectName(r)`（单源），三处集成：done 渲染改只读格、`cellUpdate` 在 time/biz_type/amount 变更时把重算名称并入同一次 PATCH、`migrateWinToDone` 迁移时生成。名称仍存 `project_name` 字段，下游（Excel/财务看板/PDF/飞书）零改动。

**Tech Stack:** 纯 HTML+JS 单文件；测试 jsdom（e:\tmp\sdd-test，node 直跑）。

**Spec:** `docs/superpowers/specs/2026-11-27-完成阶段项目名称自动生成-design.md`

## Global Constraints

- 改动仅 `贸易金融业务管理系统（Supabase）.html`；每个 Task 提交前 `cp` 同步 `index.html`，两文件一起 commit（项目 CLAUDE.md 铁律）
- trade_stats 表结构零变更；project_name 仍落库
- 名称生成必须与源字段变更合并为**同一次 PATCH**，不多发网络请求
- 存量保护：渲染/加载老记录不改名、零 PATCH；只有迁移和源字段变更才生成
- 测试命令：`cd /e/tmp/sdd-test && node <文件>.test.mjs`；全量 `bash run-suite.sh`（退出码 0 = 全绿）
- 拼接值一律经 `escHtml` 渲染（bank/biz_type 属用户可控文本）

## Review Focus

1. 脏时间文本（`2026//9`、`25/7`、带空格、空串）→ 按位数规则规整或保留原文，不崩 → Task 1 向量
2. 金额边界（0 / null / 小数 750.5 / 大额 45000）→ 0 与空无括号段、小数去尾零、≥10000 万换算亿 → Task 1 向量
3. 老手写名记录 → 打开页面原样显示、零 PATCH，不被静默改写 → Task 2 B 段
4. XSS：bank 含 `<img src=x onerror=…>` → 只读格转义为纯文本 → Task 2 B 段夹具
5. 迁移行字段缺失（bank/time 空）→ 空段拼接出残缺名但迁移流程不失败 → Task 4 D 段
