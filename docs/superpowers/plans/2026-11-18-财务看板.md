# 财务看板 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为贸易金融系统新增密码保护的财务看板（利润汇总＋项目收入明细＋成本录入四页签＋追加月份列＋导出），完成表勾选框统一所有利润口径（含飞书日报），并导入 Excel 历史成本数据。

**Architecture:** 沿用单文件 HTML + Supabase PostgREST：trade_stats 加 `profit_included` 布尔列、新表 `finance_costs` 存成本（单位元）；前端新增 `FinanceStats` 对象（照抄 LoanStats 的 `_cache`/`_editing` 行内编辑模式），汇总由纯函数 `finAggregate` 计算（period 字符串 → 列归属）；收款信息存 `profit_detail.payee` JSON 键，零改表。全程 TDD（jsdom 冒烟测试）。

**Tech Stack:** 单文件 HTML/ES5 风格 JS、Supabase REST（fetch）、node+jsdom 测试（e:/tmp/sdd-test/）、Python(openpyxl) 导入脚本（e:/tmp/fin_import/，不进仓库）、飞书推送 Python 脚本。

**Spec:** `docs/superpowers/specs/2026-11-18-财务看板-design.md`（已批准；口径冲突时以 spec 为准，本计划引用的行号为 2026-11-18 未改动状态，编辑前用 Grep 按锚点文本重新定位）
